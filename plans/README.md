# Plans directory

## Conventions

- Put active plans in `plans/active/`.
- Move completed, validated plans to `plans/done/`.
- Follow the template and rules in `.agent/PLANS.md`.
- Prefer one plan per meaningful milestone or feature family.
- If the task is trivial, a full plan is optional.

## Suggested file naming

`YYYYMMDD-short-slug.md`

Examples:
- `20260417-bootstrap-monorepo.md`
- `20260417-ingestion-api.md`
- `20260417-google-drive-connector.md`
